Security

Built like a vault. Audited like one, too.

Security isn't a feature page for us — it's the architecture. Every control below is on by default.

  • TrustFrame L2Sample badge
  • Ledger Integrity SealSample badge
  • PrivacyGrade ASample badge
  • CardSafe 4.0Sample badge

Controls that are on by default

  • Encrypted everywhere

    AES-256 at rest, TLS 1.3 in transit, keys in hardware security modules.

  • Hardware-key sign-in

    Passkeys and security keys for every user, enforced by admins.

  • Granular roles

    Separate who can view, initiate and approve, down to the account.

  • Real-time fraud scoring

    Every card authorisation and transfer is scored in under 40 ms.

  • Immutable audit trail

    Every action is signed, timestamped and exportable.

  • Independent audits

    Annual third-party audits and continuous penetration testing.

Defence in depth

Five independent layers, so no single failure exposes your money.

  1. L1EdgeTLS 1.3 · HSTS · rate limiting · bot scoring
  2. L2IdentityPasskeys · hardware keys · SSO/SCIM · session binding
  3. L3ApplicationRole-based access · dual approval · signed audit log
  4. L4DataAES-256 at rest · per-tenant keys in HSMs · 35-day PITR
  5. L5OperationsLeast privilege · break-glass access · 24/7 on-call

Security questions

Who can see our data?+

Only people you grant access to. Vaultline staff access requires a ticket, a second approver and is logged to your audit trail.

What happens if a card is stolen?+

Freeze it in one tap from the app or Slack. Real-time fraud scoring declines suspicious authorisations before they settle.

Are the certifications real?+

No. Vaultline is a fictional company, and the badges on this page are invented for the design concept.
